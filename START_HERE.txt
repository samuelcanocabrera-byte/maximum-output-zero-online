MAXIMUM OUTPUT: ZERO V7.1 — DOMAIN CRASH FIX

WHAT WAS FIXED
Opening a Domain without 100 Awakening and 35 CE now fails safely.
Countering a Domain or joining a three-way clash without 35 Awakening and 28 CE also fails safely.
A failed Domain attempt leaves the active Domain/clash unchanged and does not spend resources.
The Domain keypress is processed once, not twice. The round-start freeze now resets on rematches.

HOW TO UPDATE YOUR EXISTING GITHUB + RENDER GAME
1. Unzip this package and open the Maximum_Output_Zero_V7_COMPLETE folder.
2. Open public, locate index.html.
3. Replace the old public/index.html in your existing GitHub repository with this new index.html.
4. Commit your change. Render should redeploy the existing service.
5. Refresh the hosted game once Render shows Live.

All 6 characters, online multiplayer, Simple Domain, wagers, and 3-way barrier-damage clashes remain available.

To play on a Mac server instead: open Terminal inside this folder and run npm start.
